# Privacy Policy

This app is a private, single-user Home Assistant installation. It reads the owner's Google Calendar (read-only) solely so the owner can see and hear their own schedule at home.

Calendar data is stored only on the owner's computer. It is not sold or shared, except that event details the owner asks about are sent to the AI service the owner uses to answer the question. Use of Google user data complies with the Google API Services User Data Policy, including its Limited Use requirements.
